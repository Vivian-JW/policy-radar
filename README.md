## 立即部署（静态托管）

单文件、零依赖，任何静态托管环境均可（Render 已配置 `render.yaml`）。

**Nginx**
```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/policy-radar;
    index index.html;
}
```

**或直接使用各类平台**：腾讯云 COS 静态网站 / CloudBase 静态托管 / Vercel / Netlify / GitHub Pages —— 上传 `index.html` 即可。
